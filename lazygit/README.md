# 🦥 Lazygit Config

## Setup

Managed via `mise dotfiles apply` - see the root [README](../README.md).

## Theme

ANSI color names only (`gui.theme` in `config.yml`), so the terminal's light/dark theme decides the actual colors. The selected line is `yellow` + `reverse`: a yellow background with the terminal's background color as text, like `inverted yellow` in starship.

---

**Platform paths:**

- macOS: `~/.config/lazygit/config.yml`
- Linux: `~/.config/lazygit/config.yml`
- Windows: `%LOCALAPPDATA%\lazygit\config.yml`
